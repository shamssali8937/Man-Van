## 4. Governance & Search Console Action Plan
Search engines normalize common UK misspellings and punctuation variants automatically (e.g., treating *"man & van"* and *"man and van"* identically). 

1. **Strictly Avoid Intentional Misspellings**: Never inject typos into visible copy, `<title>` tags, `<h1>` headings, or schema markup. Doing so damages brand credibility and triggers automated quality penalties.
2. **Review Real Data Monthly**: Use Google Search Console's Performance > Queries filter to review low-CTR queries and long-tail impressions. Add natural conversational answers to the `/faq` page based on genuine user queries.
